## เวลาและระบบกลาง
ช้างยังปลดล็อกที่ 180 วินาที บอสที่ 300 วินาที จำนวนมอนสูงสุด 100 และสูตรความถี่เกิดเดิมไม่เปลี่ยน ไม่เร่งให้ช้างมานาที 2 เพราะลบสมาชิกในอาร์เรย์ ระบบชน/damage/EXP/กระสุน/สกิล/การ์ด/ฉาก/เสียง/เซฟยังใช้ระบบเดิม อีลิทเลือกได้เฉพาะ species ที่มีอีลิทจริงและเกิดตัวธรรมดาแล้ว

การโจมตีบอสทั้งสี่ใช้ค่าเดิม ทดสอบเทียบผลตัวเลขก่อน/หลัง 100 เฟรมต่อรูปแบบ และทดสอบบอสจริงใน browser แยกจากหลักฐาน hash

## เพิ่มมอนต่อไป
เพิ่ม ID และค่าสถานะใน game/assets/enemy-roster.js พร้อมเวลาปลดล็อกเฉพาะตัว แล้วเชื่อม renderer/animation/AI ของตัวใหม่เข้าการอัปเดตและวาดภาพกลาง ไม่ต้องมีมอนเก่าหรือช่องเก่ารอให้แทน หากยังไม่ทำ elite อย่าเพิ่มใน eliteEnemies และอย่าพยายามโหลดไฟล์ elite ที่ไม่มี ต้องทดสอบ file integrity, browser requests, spawn และ regression กบ/ช้าง/บอสทุกครั้ง

## ขอบเขตหลักฐาน
Pure tests ตรวจโครงสร้างและ numerical boss parity; browser CI ตรวจฉากจริง เลือกการ์ด ท่ากบ ช้างยิงโดน เกิดตามเวลา เคลียร์ mode เก่า ท่าบอสสามคลิปหลัก/กระสุน และ preset สกิลทั้งหมด การผ่านเหล่านี้ไม่ใช่การ deploy และไม่ใช่ FPS ของ iPad เว็บเดิมเท่านั้นเป็นปลายทาง ไม่มีการสร้างเว็บไซต์ใหม่ในงานนี้
